FAP - Floating Action Prompts - Custom Fonts Folder
===================================================

Drop any .ttf or .otf font files into this folder:
  Data\F4SE\Plugins\FloatingActionPrompts\Fonts\

Then open the in-game F1 Menu -> FAP - Floating Action Prompts:
  - Visual Style -> Prompt Font
  - QuickContainer -> QuickLoot Font
  - Info Card -> Info Card Font

Click "Refresh Fonts" if you add a file while the game is running,
then select the font and click "Save Settings".
